# Analysis

This folder contains the analytical workbooks used to move from validated SQL outputs into the reporting layer.

## What is here

- `SoFi_2026_Growth_Quality_PowerBI_Excel_Bridge.xlsx` — the analytical bridge connecting the cleaned data outputs to the final Power BI views.

## Why this matters

This is the part of the project where the analysis becomes structured and reviewable. The workbook makes it easier to see how the final dashboard tables were assembled and how the outputs map back to the underlying measures and definitions.

## What the workbook supports

- executive performance review
- customer depth analysis
- lending and funding review
- cash conversion analysis
- segment diversification
- loan originations
- credit risk review
- CFPB customer-friction proxy
- Growth Quality Index scoring

## How to use it

Use this file when you want to understand how the numbers move from raw analytical output into report-ready tables. It is a key link between the SQL work and the dashboard.
