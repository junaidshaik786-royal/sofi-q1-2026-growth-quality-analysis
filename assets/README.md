# Assets

This folder contains the visual snapshots used to communicate the project story clearly in the GitHub README and business-facing materials.

## What is here

- `executive-snapshot.svg` — a compact executive summary of the core signals: customer growth, funding context, and operational quality.
- `growth-quality-index.svg` — a visual summary of the Growth Quality Index (GQI) framework and the relative dimension scores.
- `cash-conversion.svg` — highlights the gap between GAAP profitability and operating cash flow, one of the key quality questions in the analysis.

## Why this matters

The project is as much about interpretation as it is about reporting. These visuals are the translation layer between the underlying analysis and the reader: they help show how the story is being told without hiding the caveats and context behind the numbers.

## How to use these files

Use these assets when reviewing the narrative in the main README or when presenting the project to a non-technical audience. They are designed to make the main conclusions easier to absorb quickly, while still linking back to the evidence in the documents and SQL layers.
