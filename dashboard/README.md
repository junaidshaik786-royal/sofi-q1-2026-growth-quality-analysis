# Dashboard

This folder contains the Power BI deliverables for the project.

## What is here

- `SoFi_2026_Growth_Quality_Dashboard.pbix` — the editable Power BI report used to build the dashboard view.
- `SoFi_Q1_2026_Growth_Quality_Analysis_Dashboard.pdf` — the exported dashboard summary in PDF format.

## Why this matters

The dashboard is the visual layer of the analysis. It turns the data model into a business-facing summary that highlights the major findings around customer depth, funding context, profitability, and operating efficiency.

## Relationship to the rest of the project

This dashboard is part of a larger analytical flow:

SQL outputs → Excel analytical bridge → Power BI → executive summary and presentation

It is meant to make the conclusions easier to see quickly, while the supporting documents and methodology retain the underlying detail and assumptions.
