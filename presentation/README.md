# Presentation

This folder contains the presentation materials created to communicate the final assessment in a more executive-ready format.

## What is here

- `SoFi-Q1-2026-Growth-Quality-Assessment.pptx` — editable presentation deck for stakeholder review.
- `SoFi-Q1-2026-Growth-Quality-Assessment_.pdf` — exported PDF version for easy sharing.

## Why this matters

The project is built around a business question, so the presentation layer matters. This folder packages the analysis into a concise narrative that is easier to communicate in meetings, reviews, or business updates without requiring the audience to read the entire evidence pack.

## How to use this folder

Use the presentation for the high-level story. For technical depth, traceability, and the underlying analysis, go to the SQL scripts, methodology notes, and the interactive HTML report.
