# SQL Analysis

This folder contains the SQL scripts used to build, validate, and analyze the data behind the SoFi Q1 2026 Growth Quality Assessment.

It covers schema creation, data preparation, validation logic, KPI calculations, customer-friction analysis, and the logic behind the Growth Quality Index.

Use the scripts in order

**Schema → Preparation → Analytics.**

## Included
- [Schema definitions](01_schema.sql)
- [Data preparation and validation](02_data_preparation.sql)
- [Analytical queries](03_analytical_queries.sql) — includes KPI and financial metric logic, CFPB complaint proxy analysis, and GQI score support.
