# Project Documentation

## Purpose

This folder contains the core business and analytical documentation for the SoFi Q1 2026 Growth Quality Assessment.

It brings together the requirement framing, KPI definitions, source mapping, evidence notes, and presentation support needed to explain how the assessment was built and how the conclusions should be interpreted.

## What is included

- [Business Requirements and Analytical Requirements](Business_Requirements_Analytical_Requirements.md)
- [KPI Dictionary](KPI_Dictionary.md)
- [Data Source Mapping](Data_Source_Mapping.md)
- [CFPB Evidence Notes](CFPB_Evidence_Notes.md)
- [Executive Business Analysis Summary](Executive%20Business%20Analysis%20Summary.docx)

## How to use this folder

Use these documents in order:

1. Review the business and analytical requirements to understand the objective and scope.
2. Use the KPI dictionary to interpret the definitions and denominators.
3. Check the source mapping for traceability across the evidence base.
4. Review the CFPB notes to understand the limitations and interpretation of customer-friction signals.
5. Use the executive summary for a concise stakeholder-facing narrative.

## Why this matters

Strong business analysis is not only about a final chart or scorecard. It is about defining the question clearly, documenting the evidence, making assumptions explicit, and ensuring the final interpretation is defensible.

This folder is where that analytical discipline becomes visible.
