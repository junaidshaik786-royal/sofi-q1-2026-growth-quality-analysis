# Documents

This folder contains the evidence pack behind the SoFi Q1 2026 Growth Quality Assessment. It is the project’s analytical backbone — the place where the business question, the KPI logic, the source mapping, and the caveats are documented.

## What is here

- `Business_Requirements_Analytical_Requirements.md` — outlines the business objective, the analytical scope, and the design of the assessment.
- `Data_Source_Mapping.md` — maps each metric back to its source and explains how the public data was connected to the final analysis.
- `KPI_Dictionary.md` — defines the core metrics, formulas, and interpretation logic used in the project.
- `CFPB_Evidence_Notes.md` — explains how the CFPB complaint database was used as a customer-friction proxy and what limitations apply.
- `SoFi_Q1_2026_Growth_Quality.html` — interactive HTML version of the core analysis for browser-based review.
- `Executive Business Analysis Summary.docx` — short-form executive summary for business-facing communication.

## Why this matters

This is where the project shows its discipline. The analysis is not just a set of charts; it is a documented process that explains what was measured, why it mattered, and what the limits of the evidence were.

## How to use this folder

Start with the business requirements and KPI dictionary, then work through the source mapping and evidence notes. The HTML report is the easiest way to follow the full narrative without digging through all of the raw documentation at once.
