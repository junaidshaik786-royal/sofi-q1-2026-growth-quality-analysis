# Executive Presentation

This folder contains the final presentation package for the SoFi Q1 2026 Growth Quality Assessment.

The presentation is the executive-facing summary of the project: it translates the analytical findings, scorecard logic, and supporting evidence into a concise narrative for stakeholders. It is designed to communicate what looks strong, what requires caution, and where the evidence remains directional rather than definitive.

## Included outputs

- [Executive Presentation PDF](SoFi-Q1-2026-Growth-Quality-Assessment_.pdf)
- [Executive Presentation PowerPoint](SoFi-Q1-2026-Growth-Quality-Assessment.pptx)

## How to use this folder

- Open the PDF for a quick stakeholder-ready summary.
- Use the PPTX file when editing, presenting, or tailoring the narrative for a live audience.
- Review the dashboard, KPI dictionary, and methodology alongside the presentation to understand the underlying evidence and scoring logic.

## Presentation lens

This is a decision-support presentation, not an official SoFi management document. It reflects the project’s public-source analysis, analytical assumptions, and disclosure commitments.
