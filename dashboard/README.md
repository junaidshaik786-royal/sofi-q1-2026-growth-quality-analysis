# Dashboard and Reporting Outputs

## Purpose

This folder contains the final reporting outputs used to communicate the SoFi Q1 2026 Growth Quality Assessment to stakeholders.

The dashboard and its companion materials convert the analytical evidence into a business-ready story, showing how the underlying metrics, scorecard logic, and public-source validation support the final assessment.

## Included outputs

- [Power BI Dashboard PDF](SoFi_Q1_2026_Growth_Quality_Analysis_Dashboard.pdf)
- [Power BI File](SoFi_2026_Growth_Quality_Dashboard.pbix)

## How to use these files

- Open the PDF for a quick stakeholder-facing overview.
- Use the PBIX file for interactive exploration and deeper review.
- Pair the dashboard with the KPI dictionary, source mapping, and methodology to understand the logic behind the charts.

## Reporting lens

This dashboard should be interpreted as a decision-support artifact, not an official SoFi management scorecard. It reflects the project’s analytical framework, assumptions, and public-source evidence.
